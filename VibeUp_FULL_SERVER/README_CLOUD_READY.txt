VibeUp CLOUD READY

Теперь:
- OAuth token Яндекс Диска не попадает в APK.
- Встроенный Hush удалён из APK.
- Admin POST/PATCH/DELETE защищены VIBEUP_ADMIN_KEY.
- Admin -> backend -> Yandex Disk -> catalog -> VibeUp.
- Каталог обновляется автоматически каждые 30 секунд и при возврате в приложение.
- Онлайн-аудио идёт через backend /api/tracks/:id/stream.
- Stream поддерживает Range для перемотки.
- Offline сохраняется во внутреннюю память приложения.

Тест:
1. Запусти start-server.bat.
2. Введи Yandex OAuth token только в окно backend.
3. Введи свой приватный admin key.
4. Открой /admin и введи тот же admin key.
5. Добавь MP3 + обложку.
6. Открой приложение; новый трек появится автоматически.
7. Нажми скачать офлайн и проверь воспроизведение без интернета.

Для публичного релиза server.js надо разместить на публичном HTTPS backend, а SERVER_URL в www/index.html заменить на его адрес. Пользовательский APK не должен содержать Yandex OAuth token.


ВАЖНО: локальный IP больше не должен использоваться в релизном APK.
В www/config.js укажи публичный HTTPS-адрес backend. Сам backend можно разместить на VPS/облачном хостинге; тогда пользователи из любой сети смогут пользоваться каталогом.
После скачивания трек хранится во внутренней памяти VibeUp и для его воспроизведения интернет/backend не нужен.

Распознавание:
- В приложении добавлена кнопка «Что играет?».
- Она записывает короткий фрагмент с микрофона и отправляет его на /api/recognize.
- Backend использует AudD, если задан VIBEUP_AUDD_TOKEN.
- Токен AudD не хранится в APK.
- Для полностью официального варианта на Android позже можно заменить этот модуль на ShazamKit.
